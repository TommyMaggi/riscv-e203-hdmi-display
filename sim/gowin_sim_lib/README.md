# Gowin simulation library

Place `prim_sim.v` here, copied from your Gowin EDA installation (`IDE/simlib/gw2a/prim_sim.v`).
It provides the behavioural models of the Gowin primitives used by the dual-port RAM (`rtl/ip/gowin_dpb.v`) and is required by `sim/sim_run_sys_tb.sh`.
The file is not redistributed in this repository.
